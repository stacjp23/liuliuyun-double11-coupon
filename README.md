## 优惠码之外，这家的真实短板

六六云官网的公告页我从头翻到尾，运维类公告占了大多数，而且有几条读起来不太舒服。

2026 年 8 月 17 日，美国 US4 节点物理服务器严重硬件故障宕机，公告原文写“该服务器存储介质已物理损坏，其上实例的磁盘数据无法恢复”。另一条 GTT 部分服务器故障的公告（涉及 216.36.100.* 到 216.36.103.* 四个段），最后的处理结果是“服务器硬件故障已修复，数据无法恢复，系统已重装，平台补偿 3 天时间”。国际带宽 net-usd-cgt 节点那次也是恢复后系统重装。同一类表述在公告里出现了至少两次。

美国部分实例换过 IP：原来用 38.34.20.* 到 38.34.28.* 段的机器，在公告发布后 24 小时内免费换到 38.69.24x.x 段，原 IP 停止使用。系统、数据、套餐和续费价格都不变，但对你把 IP 绑在业务上、或者对外公布过 IP 的用途来说，这就是一次被动迁移。

“墙高峰”的公告发过不止一次。官方描述的现象是服务器 Ping 得通但 SSH 或业务端口连不上，TCP 连接在中国大路段受限，给出的建议是“关机保护 IP，或者升级搭建技术”。这句话的意思是：大陆方向的连接稳定性有波动，而且这件事官方也没法完全兜住。此外还有香港 HK3 节点故障、德国机房温度过高、香港机房电力模块故障、Cogent 光缆中断这些零星事故。

这些材料放在一起，能得出一个很具体的结论：这家便宜是真的，但你不能把唯一一份数据放在它上面。重要数据自己定期备份到本地或另一家，先买月付跑一段时间再考虑长期，别一上来就年付。

## 常见问题

### DOUBLE11 续费还能用吗？

能。官方公告写的是“全站八折，循环有效”，折扣跟着产品走，续费时仍是八折价，不用重新填码。这也是这次活动比一般首单折扣实在的地方。

### 特价产品能不能叠加 DOUBLE11？

不能。公告明确写“特价产品不参与”。官方没有公布特价产品的具体名单，结账页填码后价格没变化，就是这单不参与。

### 有没有比八折更低的优惠码？

六六云官网公告里目前只有 DOUBLE11 这一个在有效期内的码。第三方优惠码站上流传着一些长期码（比如所谓月付九折、年付七折的），我在官网公告里找不到对应的说明，所以不写进这篇文章。要更低的价，等下一次官方活动，或者看年付方案的结算价。

### 买了不满意能退款吗？

可以，48 小时内无理由退款，特价产品除外。这条写在六六云开学季活动和菲律宾机房上架的公告里。

### 付款和界面方便吗？
